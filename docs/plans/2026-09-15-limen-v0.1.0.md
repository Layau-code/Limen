# Limen v0.1.0 实施计划

> 执行要求：按任务顺序实施，每个行为先写失败测试，再写最小实现；每个任务独立提交，生产方法使用简体中文用途注释。

**目标：** 交付具备多目标 Fallback、共享时间预算、并发熔断、可解释路由及完整运行资产的 Limen v0.1.0。

**架构：** 模型注册表保存有序目标，Router 统一拥有完整请求预算和单次尝试策略，Provider 只执行一次协议调用。每个目标绑定进程内熔断器，HTTP 层转发结果并公开不含敏感信息的路由决策。

**技术栈：** Go 标准库、`net/http`、`context`、`log/slog`、`httptest`、Docker、GitHub Actions。
