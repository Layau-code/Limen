# Limen PostgreSQL 迁移并发边界计划

## 目标

保证多个 Limen 实例同时启动时，数据库迁移只由一个事务执行，其他实例等待同一个锁，而不是竞争 DDL。

## 规则

- `ApplyMigrations` 在事务开始后立即获取固定事务级 advisory lock。
- 版本表检查和全部内置迁移继续在同一事务中执行。
- 锁随事务提交或回滚自动释放，不新增持久化锁状态。
- 应用 Store 的租户 RLS 和业务锁不复用迁移锁。

## 验收

- 单元契约确认迁移使用 `pg_advisory_xact_lock`。
- PostgreSQL 集成测试持有迁移锁时，第二个迁移事务必须等待释放。
- 迁移、RLS、并发准入和恢复测试保持通过。
