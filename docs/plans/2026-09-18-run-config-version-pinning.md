# Run 配置版本固定

## 目标

配置发布后，已经开始的 Agent Run 仍使用创建时记录的模型目录、价格和路由参数，避免同一 Run 在中途改变决策语义。

## 实现

- Run 请求发现当前 Router 版本不同于 `config_version` 时，从租户隔离的配置存储加载不可变版本。
- Router 使用该目录生成 DecisionInput，并让 Executor 使用该版本的路由超时和熔断参数。
- 历史目标的熔断器快照在配置切换后继续保留，避免旧 Run 因当前目录替换而被误判为目标不可用。
- 配置版本不存在或内容无效时返回 `config_version_unavailable`，不静默降级到当前版本。

## 验收

- 发布新版本后，旧 Run 仍把请求发送到旧版本目标，并保留旧配置版本响应摘要。
- 旧版本目标的执行参数和决策快照保持固定；无 Run 请求继续使用当前 Router。
- 版本缺失时不调用 Provider，返回稳定错误码。
