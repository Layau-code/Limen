# Limen 幂等键边界收敛计划

## 目标

为控制面幂等键建立统一、可解释的输入边界，避免异常 Header 直接进入内存索引、PostgreSQL 唯一索引和审计哈希。

## 规则

- 读取后裁剪首尾空白。
- 仅接受可见 ASCII 字符，拒绝控制字符和空值。
- 长度上限为 256 字节；无效值使用现有 `idempotency_key_required` 错误码拒绝。
- 规则只约束 HTTP 入口，领域 Store 继续由调用方传入已经规范化的幂等键。

## 验收

- 合法键保持裁剪后的稳定值。
- 超长键和控制字符被拒绝。
- 现有控制面幂等、PostgreSQL 集成和 OpenAI 兼容测试不受影响。
