# Limen 配置发布跨实例传播计划

## 目标

配置版本发布后，所有共享 PostgreSQL 的 Limen 实例都能刷新本地 Router；通知只携带租户和版本哈希，不携带配置正文。

## 实施

1. 在发布事务中写入 `limen_config_changes` PostgreSQL 通知。
2. 增加自动重连的配置监听器和租户过滤。
3. 监听到通知后读取数据库事实并通过 `ReplaceRegistryWithPolicy` 原子替换目录。
4. 每 5 秒轮询已发布版本，弥补 NOTIFY 丢失或监听器重连窗口。

## 验收

- 多实例发布通知只包含租户和版本哈希。
- 收到通知后不信任载荷正文，始终从数据库读取完整配置。
- 通知丢失时轮询仍能最终激活新版本。
- Router 替换保留已有熔断器语义，配置版本保持只读。
