# Limen v1.0.0-rc1 发布说明

## 发布定位

这是 Limen 的首个发布候选版本，聚焦 Agent Run 治理、能力契约路由、可解释决策、可靠 Fallback、普通/SSE 协议转换和安全结算。版本不宣称支持 Responses、Tools、多模态、第三 Provider 或大规模多地域部署。

## 发布范围

- OpenAI Chat Completions 和 Anthropic Messages 的文本普通响应与 SSE；
- 逻辑模型注册表、能力契约、确定性 ExecutionPlan、Explain、Replay 和配置 diff；
- Run 软预算、并发准入、幂等、租约、取消、PostgreSQL RLS 和结算恢复；
- Provider 错误分类、能力安全 Fallback、熔断、安全出站和敏感信息脱敏；
- 离线发布门禁、真实兼容协议联调、二进制冒烟、基准和构建元数据。

## 验证记录

本次 RC 已完成以下验证：

```text
make release-check       # 通过
make release-live        # 通过
make release-build       # 目标提交上执行
limen version             # 版本、提交和构建时间均已注入
```

本次真实联调使用 DeepSeek 官方兼容 endpoint，验证了 OpenAI Chat Completions 和 Anthropic Messages 两种协议的模型列表、普通响应和 SSE；该结果证明协议适配和端到端转发成立，不等同于官方 OpenAI 或 Anthropic 服务商联调。

## 安全边界

- Provider Key 只通过本机环境或受保护的本地文件注入，不进入仓库、日志、Prompt、Response 或发布说明；
- 发布证据只记录命令结果、模型公开名称和提交标识，不记录完整响应正文；
- `soft_budget` 是事后停用阈值，不是硬消费上限；
- PostgreSQL、规模、成本、多地域和第三 Provider 能力仍需后续专项验证。
